# WRGD データセット評価基準

## 目的

各データセットを同じ基準で評価するためのルールを定義する。

## 総合評価

★★★★★：WRGDの主要データとして採用する

★★★★☆：補助データとして採用する

★★★☆☆：条件付きで利用する

★★☆☆☆：限定用途のみ利用する

★☆☆☆☆：採用しない

## 評価項目

|項目|評価内容|
|------|------|
|世界対応|対象地域の広さ|
|精度|標高・道路データの精度|
|ライセンス|利用条件の自由度|
|Python|Pythonから利用しやすいか|
|ダウンロード|取得しやすさ|
|更新頻度|更新の継続性|
|総合評価|WRGDでの採用判断|

## 評価ルール

- 必ず公式情報を確認する
- 出典を記載する
- 推測では評価しない
- 評価理由を記載する
- 他データセットと比較できるよう統一する

## 評価方法

各項目を10点満点で評価する。

|項目|配点|
|---|---:|
|世界対応|2点|
|精度|2点|
|ライセンス|2点|
|Python|1点|
|ダウンロード|1点|
|更新頻度|1点|
|コミュニティ・実績|1点|

合計10点で評価する。

### 星評価

- 9～10点：★★★★★
- 7～8点：★★★★☆
- 5～6点：★★★☆☆
- 3～4点：★★☆☆☆
- 0～2点：★☆☆☆☆
