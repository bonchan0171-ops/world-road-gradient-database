# OpenTopography

## 概要
OpenTopography は、単一の標高データセットではなく、LiDAR や DEM などの高解像度地形データを検索・取得・処理できるオンライン基盤である。WRGD のような道路勾配データベース構築では、単体の標高ソースとしてではなく、データ発見・取得・比較評価の入口として重要な役割を持つ。

特に、道路沿いの局所地形を扱う際には、OpenTopography から取得できる高解像度 LiDAR や地域データが有効な場合がある。世界規模の標高データセットに加え、局所的で高解像度の地形データを補完的に取り入れられる点は、WRGD の将来拡張性にとって大きな利点である。

## 提供元
OpenTopography は、University of California San Diego の San Diego Supercomputer Center、EarthScope Consortium、Arizona State University の School of Earth and Space Exploration の共同プロジェクトとして運用されている。

## 公式サイト
https://opentopography.org/

## データ種別
OpenTopography は、以下のような地形・標高データを提供するプラットフォームである。

- LiDAR 点群データ（LAS/LAZ など）
- DEM / DTM / DSM などのラスデータ
- 派生製品（hillshade、relative elevation model など）
- 水文解析向けの処理済みデータ

## 対象地域
対象地域はデータセットごとに異なる。世界規模の公開データに加えて、米国・欧州・一部の地域を中心に高解像度の LiDAR データが提供されることが多い。

## 解像度
解像度はデータセットごとに大きく異なる。LiDAR 点群は数 cm〜数 m 級の高解像度データもあり、DEM では数メートル〜数十メートル級のものまで幅広い。

## 座標系
座標系はデータセットごとに異なる。多くは緯度/経度または UTM などの投影座標で提供されるため、WRGD では再投影と CRS 管理が必要になる。

## ファイル形式
主に以下の形式が利用される。

- LiDAR 点群: LAS / LAZ
- ラスター: GeoTIFF など
- 派生データ: GeoTIFF、画像、メッシュデータなど

## Pythonで利用するライブラリ
- rasterio: GeoTIFF やラスデータの読み取り・処理用
- laspy: LiDAR 点群の読み取り用
- numpy: ラスター・点群の数値処理用
- geopandas / shapely: 空間解析用
- requests: OpenTopography の API や Web インターフェースからの取得用

## ライセンス
OpenTopography の公式ページでは、NSF で支援・提供されるデータセットは一般に無償公開される一方、特定の federated データや有償・限定アクセスのデータについては利用条件が異なると説明されている。したがって、各データセットごとの利用規約・引用方針・アクセス制限を確認する必要がある。

## 長所
- 単一の DEM ではなく、LiDAR や高解像度地形データを横断的に取得できる。
- 世界規模の標高データと局所的な高解像度データをつなぐ入口として使いやすい。
- API や Web インターフェースにより、検索・取得・利用の再現性を高めやすい。
- 道路周辺の微地形を評価する用途において、他の全球 DEM では不足しがちな補完データを提供し得る。

## 注意点
- OpenTopography 自体は「データセット」ではなく「データ配信基盤」であるため、利用対象はデータセットごとに異なる。
- データの解像度、カバレッジ、ライセンス、提供形式は各データに依存する。
- LiDAR や高解像度データは大容量になりやすく、処理・保存コストが高くなることがある。
- 道路勾配計算においては、点群から DEM を作成する前処理や、地表と植生・建築物の区別が必要になる。

## WRGDでの利用方法
- 道路勾配の比較評価用に、局所的な高解像度 LiDAR データを追加的に取得する。
- AW3D30 や Copernicus DEM などの全球データに対し、OpenTopography 上の高解像度データを使って精度検証を行う。
- 道路近傍の微地形・橋梁・切土・盛土などの局所特徴を補完的に確認する。
- 将来的には、OpenTopography の API を通じてデータ検索・取得を自動化し、WRGD のデータ収集パイプラインに組み込む。
