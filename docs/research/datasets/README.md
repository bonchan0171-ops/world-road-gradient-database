# 標高データセット調査

## 概要

このディレクトリには、WRGD（World Road Geometry Database）で利用する標高データセットの調査資料を格納します。

Sprint 1では、道路勾配データベースの構築に適したDEM（Digital Elevation Model）を選定することを目的としています。

## 調査方針

各データセットについて、以下の観点で評価を実施します。

* データ概要
* カバー範囲
* 解像度・精度
* データ形式
* ライセンス
* Pythonでの利用しやすさ
* 道路勾配計算への適合性
* WRGDへの採用可否

すべての調査資料は同一フォーマットで作成し、比較しやすい構成とします。
