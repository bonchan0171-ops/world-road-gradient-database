# DATASET COMPARISON

## 1. 概要

Sprint 1 では、WRGD の標高データソース候補として、AW3D30、SRTM、Copernicus DEM、FABDEM、OpenTopography を比較した。比較の目的は、道路勾配データベース構築に向けて、世界規模で利用可能かつ、道路勾配計算に適したデータセットを選定することである。

本比較では、単なる機能一覧ではなく、WRGD の設計判断に直結する観点を重視する。特に、以下の点を中心に評価した。

- 世界規模で利用可能か
- 道路勾配計算にどの程度適しているか
- 導入しやすさと Python との相性
- ライセンスと再利用性
- 将来の保守・拡張性

## 4. WRGD観点での評価

### 4.1 世界規模で利用可能か

- AW3D30: ほぼ全球をカバーし、世界規模の実装に適している。
- SRTM: 陸域の大部分をカバーし、世界規模の初期実装に適している。
- Copernicus DEM: 全球をほぼカバーし、世界規模の標高基盤として実用的である。
- FABDEM: 全球をカバーするが、品質のばらつきと除去処理の特性に注意が必要である。
- OpenTopography: データセットごとに異なり、単体としての世界対応は限定的だが、補完的な利用には強い。

### 4.2 精度

- AW3D30: 30 m 級の解像度で、道路勾配用途には十分な性能を期待できるが、DSM 特性に注意が必要。
- SRTM: 30 m 級の解像度は概略勾配計算には有効だが、局所精度はやや不安定である。
- Copernicus DEM: 30 m 級で実装しやすく、比較的安定した品質を期待できる。
- FABDEM: 地表高モデルとして有望だが、局所微地形や除去処理の品質に依存する。
- OpenTopography: 高解像度データの活用が可能だが、道路勾配用途ではデータセットごとの評価が必要である。

### 4.3 導入しやすさ

- AW3D30: 公式配布と利用条件の確認が必要だが、実装自体は比較的容易である。
- SRTM: 取得と利用が比較的容易で、初期実装に適している。
- Copernicus DEM: 配布・取得のしやすさが高く、実装導入に適している。
- FABDEM: 公開性は高いが、利用条件と品質確認の手間がある。
- OpenTopography: 基盤としては便利だが、データセットごとの条件確認が必要である。

### 4.4 Pythonとの相性

- 5つとも、GeoTIFF や点群データを扱う主要ライブラリで比較的扱いやすい。
- 特に AW3D30、SRTM、Copernicus DEM、FABDEM はラスデータとして Python パイプラインに組み込みやすい。
- OpenTopography は LiDAR や API 取得を含めるため、処理パイプラインを構築する必要がある。

### 4.5 将来性

- AW3D30: 長期的に利用価値が高いが、DSM としての特性は継続して確認が必要である。
- SRTM: 旧世代データとしての位置付けがあるが、ベースライン用途として依然有効である。
- Copernicus DEM: 将来性が高く、継続的な更新と実装のしやすさが強みである。
- FABDEM: 地表高モデルとしての発展性があり、道路解析における新しい候補として注目される。
- OpenTopography: データ基盤としての拡張性が高く、研究・実装双方で将来性が大きい。

### 4.6 保守性

- AW3D30、SRTM、Copernicus DEM は、比較的明確な配布・公開体制を持つ。
- FABDEM は新しいアプローチだが、長期運用や品質評価の積み上げが必要である。
- OpenTopography はプラットフォームとして保守性が高いが、データそのものの品質は各データセットに依存する。

### 4.7 ライセンス

- SRTM と Copernicus DEM は比較的利用しやすい公開データとして位置づけられる。
- AW3D30 と FABDEM は利用条件の確認が必要だが、商用・研究で利用可能なケースが多い。
- OpenTopography はデータごとに条件が異なり、個別の確認が必要である。

### 4.8 道路勾配計算との適合性

- AW3D30: 主要候補として高い適合性を持つ。
- SRTM: 初期実装やベースライン用途として適している。
- Copernicus DEM: 主要候補として非常に有望である。
- FABDEM: 地表表現の改善により、道路勾配用途への適合性が高い可能性がある。
- OpenTopography: 直接の主要ソースというより、補完・検証・高解像度データ取得の用途に強い。

## 5. 総合評価

| データセット | 評価 |
|---|---|
| AW3D30 | ★★★★★ |
| SRTM | ★★★★☆ |
| Copernicus DEM | ★★★★★ |
| FABDEM | ★★★★☆ |
| OpenTopography | ★★★★☆ |

### 評価理由

- AW3D30: 世界規模で利用しやすく、30 m 級の解像度と安定した利用実績を持つため、WRGD の主要候補として優秀である。
- SRTM: 公開性と実装しやすさが高く、初期実装や比較基準として十分有効である。ただし、植生・建築物影響に注意が必要である。
- Copernicus DEM: 世界対応・実装しやすさ・品質のバランスが優れており、WRGD の第一候補に相応しい。
- FABDEM: 地表高モデルとして有望で、道路勾配用途の適合性は高いが、品質のばらつきや除去処理の影響に注意が必要である。
- OpenTopography: 高解像度地形データの入口として非常に有用だが、単体の DEM としてではなく、補完・比較・検証用途での活用が中心となる。

## 7. Sprint 1 結論

Sprint 1 の時点では、WRGD の標高データソースとしては、Copernicus DEM と AW3D30 を第一候補とする。両者は世界対応・解像度・実装容易性のバランスが良く、道路勾配計算の主要入力候補として十分に妥当である。

SRTM は初期実装や比較基準として強く、FABDEM は地表近傍の表現改善に期待できるため、第二候補として位置づける。OpenTopography は、主たる標高ソースというより、局所高解像度データの補完・比較・検証用基盤として活用するのが適切である。

### 採用理由

- 世界規模で利用できること
- 道路勾配計算に適した解像度を持つこと
- Python で扱いやすいこと
- 公開性・再利用性があること
- 将来的な比較・拡張がしやすいこと
